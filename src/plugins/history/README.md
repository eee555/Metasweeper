# 历史记录插件

自动记录每一局扫雷数据（SQLite 持久化），并提供查询、过滤、排序、计算列、录像播放与导出功能。

每局游戏结束（无论胜负）都会自动写入本地数据库，无需任何手动操作。

## 快速上手

在插件管理器中启用本插件后，主界面会出现「历史记录」标签页：

1. 点击 **查询** —— 显示全部历史记录（默认每页 50 条）；
2. 在表格上 **右键** 一条记录 —— 可以播放、导出、复制或删除；
3. 用 **过滤** / **排序** / **列设置** / **计算列** 按钮按需定制视图。

## 界面功能

### 查询与分页

- **查询**：按当前过滤、排序条件重新查询；
- 底部分页栏：**上一页 / 下一页**、页码跳转、每页条数（10 ~ 1000，可在插件设置中改默认值）；
- 分页栏右侧显示总行数与总页数。

### 过滤

点击 **过滤** 打开条件编辑器，支持多行条件组合：

- 每行：`括号` + `字段` + `比较符` + `值` + `逻辑连接`；
- 比较符支持：等于、不等于、大于/小于（含等于）、包含 / 不包含、包含子串 / 不含子串；
  - **包含 / 不包含**：逗号分隔的**多值精确匹配**（`in` / `not in`），
    如 `难度 包含 初级,中级`；
  - **包含子串 / 不含子串**：文本**模糊匹配**（`like` / `not like`），值按子串处理，
    `%` 与 `_` 只当普通字符，如 `软件 包含子串 3.3`；
    仅**文本字段**可用（数值/日期/枚举字段会提示改用「包含 / 等于」，
    因为它们的存储值并不是界面上的文本）；
- 多行之间可用 **与 / 或** 连接，并支持左右括号分组；
- 时间字段（开始时间、结束时间）可以直接填 `2024-01-01 12:00` 这样的可读格式；
- 逻辑错误（如括号不匹配）会弹窗提示，不会执行错误查询。

示例：`开始时间 > 2024-01-01` 且 `游戏状态 = 胜利` 且 `用时 < 60`、
`软件 包含子串 3.3`、`玩家 不含子串 test`。

> 关闭软件时会记住当前的过滤与排序条件，下次打开自动恢复。

### 排序

点击 **排序** 打开排序编辑器：

- 可按任意字段（含计算列）升序 / 降序排列；
- 支持多级排序（先按难度，再按用时，以此类推）。

### 列设置

点击 **列设置** 选择表格显示哪些列，支持上下移动调整顺序。

### 局面预览

鼠标悬浮在表格的 **board** 列上约 0.3 秒，会弹出该局的只读局面预览浮窗：

- 按这一局的最终局面绘制：数字（1~8 用经典配色）、地雷、标旗 / 错误标旗 / 爆炸的地雷；
- 纯预览，不能点击操作，鼠标移开（或滚动、点击、刷新数据）自动消失；
- 格子边长 24px，超大局面会自动缩小以保证浮窗完整显示在屏幕内；
- 该局没有局面数据、或已在「列设置」里隐藏 board 列时不会弹出。

### 计算列

点击 **计算列** 可以在表格中新增"派生列"，本质是 SQL 表达式：

- 表格中有 **列名 / SQL 表达式 / 结果类型** 三项，点 **添加** 新建一行；
- 表达式里可以引用任何物理字段，例如 `py_safe_div(bbbv_solved, rtime)` 即 3BV/s；
- **结果类型** 支持三种，决定该列在过滤时按数值还是按文本比较：

| 结果类型 | 适用表达式 | 过滤行为 |
|----------|------------|----------|
| `float` | 除法等带小数的表达式，如 `py_safe_div(bbbv_solved, rtime)` | 按数值比较（自动 CAST） |
| `int` | 计数类表达式，如 `py_days_since(start_time)` | 按数值比较（自动 CAST） |
| `string` | 拼接/截取等文本表达式，如 `software \|\| '-' \|\| mode`、`py_months_since(start_time) \|\| '个月前'` | 按文本比较，值原样绑定 |

- 点 **验证** 会检查所有表达式是否合法；
- 还可以在下方编辑区写 **自定义 Python 函数**（须以 `py_` 开头），供 SQL 表达式调用。

内置的默认自定义函数：

| 函数 | 作用 |
|------|------|
| `py_safe_div(a, b)` | 安全除法，除零或空值返回 0 |
| `py_safe_mod(a, b)` | 安全取模，除零或空值返回 0 |
| `py_days_since(ts)` | 微秒时间戳距今天数（今天 = 0） |
| `py_months_since(ts)` | 微秒时间戳距今月数（当月 = 0） |

默认已预置若干计算列（3BV/s、IOE、THRP、CORR、距今天数等），可自由删改。

### 右键菜单

在表格记录上右键：

| 操作 | 说明 |
|------|------|
| **播放** | 用元扫雷主程序打开该局录像回放 |
| **导出录像** | 另存为 `.evf` 文件 |
| **复制 JSON** | 把该行所有可见字段复制为 JSON 到剪贴板 |
| **删除** | 删除该条记录（含录像数据），有确认弹窗，**不可恢复** |
| **刷新** | 重新加载数据 |

## 插件设置

在插件管理器中打开本插件的设置页：

| 设置项 | 默认 | 说明 |
|--------|------|------|
| 小数位数 | 2 | 表格中浮点数显示的小数位数 |
| 每页条数 | 50 | 打开页面时默认的每页记录数 |
| 局面预览 | 开 | 鼠标悬浮在 board 列时是否弹出局面预览浮窗，保存设置即生效 |

计算列、过滤、排序、列显示状态都会自动保存，无需手动备份。

## 数据存储

数据库与配置都位于插件数据目录：

```
<数据目录>/plugin_data/HistoryPlugin/
├── history.db                  # SQLite 数据库（元数据 + 录像数据）
└── history_show_fields.json    # 列显示配置
```

- 录像二进制数据与元数据**分开存放**（`replay_data` 子表），并自动压缩，旧数据会在后台静默迁移压缩，不影响使用；
- 隐藏大量旧记录后空间不会立即释放，重启插件后台清理完成即回收（自动 VACUUM）；
- 换电脑迁移：直接拷贝 `HistoryPlugin` 整个文件夹即可。

## 字段速查

| 字段 | 含义 | 字段 | 含义 |
|------|------|------|------|
| `replay_id` | 记录编号 | `game_state` | 结局状态（胜利/失败/重开等） |
| `nf` | 是否 NF（无标旗） | `row` / `column` / `mine_num` | 盘面行、列、雷数 |
| `rtime` | 用时（秒） | `left` / `right` / `double` | 左键、右键、双击次数 |
| `level` | 难度（3 初级 / 4 中级 / 5 高级 / 6 自定义） | `cl` / `ce` | 点击次数、有效点击数 |
| `bbbv` / `bbbv_solved` | 3BV 总数、已解决数 | `zini` | ZINI |
| `flag` | 标旗数 | `path` | 鼠标路径长度 |
| `start_time` / `end_time` | 开始 / 结束时间 | `mode` | 游戏模式（标准、无猜等） |
| `op` / `isl` / `pluck` | OP 区间数、ISL 区间数、Pluck | `is_official` / `is_fair` | 是否正式 / 公平局 |

## 常见问题

**Q：看不到最近一局的记录？**
点击右键菜单的 **刷新** 或顶部 **查询** 按钮即可（插件正常情况下会自动刷新）。

**Q：表格很卡 / 记录太多？**
用 **过滤** 缩小范围，或在设置里把每页条数调小；也可以把不需要看的列隐藏掉。

**Q：计算列写错了，能恢复默认吗？**
删除所有自定义列后，重新启动插件即可恢复默认的计算列配置。

**Q：误删了记录怎么办？**
删除不可恢复。建议定期备份 `history.db` 文件。

**Q：其他插件能读我的历史记录吗？**
可以。本插件注册了只读的 `HistoryService` 服务，其他插件（如统计插件）可通过服务接口查询记录，但不能修改或删除数据。
